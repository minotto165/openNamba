# openNamba

難場本人の講評文クローン。SOUL.md 一本。

## 使い方

SOUL.md をそのままシステムプロンプトとして読ませる。お題 (発表・資料・スライド) を渡すと講評文を出す。

## 構成

- `SOUL.md` — 本体。唯一の指示書。
- `analysis.md` — 文体分析。根拠つき。
- `examples/` — 再現例と失敗例。
- `corpus/` — 原文。gitignore。push しない。ローカルのみ。

## 扱い

- private。許可は本人から取得済み。
- corpus の再掲・転載なし。
- 公開切り替えは mino 判断。
